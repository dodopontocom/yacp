# Emojis animados

Estes arquivos `.tgs` são animações Lottie comprimidas com gzip, no formato
usado pelos emojis animados do Telegram. Eles são carregados somente quando o
Mini App detecta que está rodando dentro do Telegram.

| Arquivo     | Emoji |
| ----------- | ----- |
| `gem.tgs`   | 💎    |
| `fire.tgs`  | 🔥    |
| `bolt.tgs`  | ⚡    |
| `whale.tgs` | 🐳    |
| `crown.tgs` | 👑    |
| `party.tgs` | 🎉    |

As animações foram obtidas do projeto
[`ilyhalight/telegram-emoji-effects`](https://github.com/ilyhalight/telegram-emoji-effects).
Os arquivos originais são criados pelo Telegram e devem ser usados de acordo
com os termos do Telegram.
